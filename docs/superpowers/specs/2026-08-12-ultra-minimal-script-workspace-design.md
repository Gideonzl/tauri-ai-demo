# 超极简脚本工作区设计

## 目标

在已简化的脚本工作区基础上继续做减法，使默认编辑视图接近终端工具：脚本内容优先，页面只保留运行入口与按需菜单。

## 默认编辑体验

- 脚本名称和描述使用无厚重容器的文本式输入；仅在悬停或聚焦时显示一条细灰色/主题色边线。
- 脚本内容编辑器占据绝大多数可用高度。
- 取消显式“保存”按钮，改为防抖自动保存：编辑名称、描述、内容或标签后保存到本地脚本库。
- 顶部操作只保留一个“运行”主按钮和一个纯三点“更多”图标按钮。
- 三点菜单保留专注编辑、AI 编写、AI 审查、复制、版本历史与删除。

## 低频信息与操作

- 移除编辑页常驻的调度器状态、保存状态、风险说明与调度说明。
- 运行设置收敛为单行摘要：`目标 · 未选择` 或 `目标 · 已选 N 台`，点击才展开目标、标签和风险级别。
- 左侧脚本库只保留图标化新建与溢出菜单；导入、导出仅在溢出菜单中显示。
- 计划任务与运行记录继续为独立页签，编辑页不展示其摘要或提示。

## 自动保存规则

- 空白新建脚本在用户填写脚本内容前不创建持久化记录。
- 已存在脚本的字段变更在短暂防抖后自动写入现有 `scriptAutomation` store。
- 新脚本首次出现非空内容后自动创建，并成为当前脚本。
- 自动保存复用现有 `upsertScript`，不改变版本历史和执行数据模型。
- 运行操作在保存尚未触发时先同步保存，保证运行的是当前编辑内容。

## 验收标准

1. 默认工具栏只显示运行按钮和图标化更多菜单，不显示保存按钮或文字型“更多”。
2. 输入字段没有蓝色粗框、卡片化外壳或常驻保存提示。
3. 编辑变更自动保存，重新选择脚本后内容不丢失。
4. 运行设置默认收起，仅显示目标摘要。
5. 导入、导出、AI、版本历史、复制、删除和专注编辑仍可访问。
6. 通过 UI 回归、构建、Rust 测试和桌面启动检查。
