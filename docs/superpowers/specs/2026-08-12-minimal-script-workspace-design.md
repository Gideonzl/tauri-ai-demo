# 极简脚本工作区设计

## 目标

将“脚本计划”从多面板管理后台收敛为以脚本编辑为中心的工作区。默认视图让用户一眼完成三件事：选择脚本、编辑脚本、保存或运行脚本。

## 范围

- 保留脚本库、脚本编辑、立即运行、计划任务和运行记录。
- 不删除现有脚本、计划、版本、AI 辅助和导入导出能力；将低频能力移至按需入口。
- 不改变脚本存储、计划任务调度、执行权限或 AI 对话的数据逻辑。

## 默认编辑页

### 左侧脚本库

- 顶部只保留搜索框、`+` 新建按钮和溢出菜单。
- 导入、导出位于溢出菜单，不再占用常用工具栏空间。
- 脚本条目仅显示名称、简短描述和状态点；最后运行详情不在列表逐条展开。
- 空状态只提供一个新建动作，导入从溢出菜单进入。
- 保持现有左右拖拽调整宽度能力。

### 中央编辑区

- 名称和描述保留为紧凑的两行输入，使用中性灰色边框；聚焦时不使用厚重蓝色描边。
- 标准工具栏仅显示：保存、运行、更多。
- 更多菜单包含：专注编辑、AI 编写、AI 审查、复制、版本历史、删除。
- 脚本编辑器成为页面主要区域，默认占据剩余高度。
- 标签不再固定显示；在更多菜单或运行设置中提供编辑入口。

### 运行设置

- 编辑器下方使用一行可展开的“运行设置”。
- 收起时只显示目标摘要，例如“未选择目标”或“已选 2 台主机”。
- 展开后才显示多选主机、标签和脚本风险等级。
- “计划任务”不再混在编辑页；用户通过独立页签管理计划任务。
- 取消常驻的调度说明、风险大卡片和独立执行目标大区。

### 运行反馈

- 点击运行前，若未选择目标、脚本为空或存在参数缺失，只显示贴近运行按钮的简短原因。
- 点击运行后仍沿用现有的执行预览、权限策略和运行记录。
- 高风险提示只在确有风险或进入运行流程时出现，不占用默认编辑空间。

## 计划任务与运行记录

- 保留既有“计划任务”和“运行记录”页签及数据功能。
- 这两个页面在编辑页之外单独呈现，避免三类任务同时争夺编辑空间。
- 不新增审批、团队管理或角色相关功能。

## 响应式行为

- 当脚本库变窄时，新建按钮退化为图标，导入导出维持在溢出菜单。
- 当编辑区变窄时，工具栏中的“更多”始终保留，低频操作不换行撑高页面。
- 运行设置在窄屏改为单列可展开内容，编辑器仍优先占据高度。

## 验收标准

1. 新建空脚本时，默认视图不出现独立目标大区、风险卡、标签输入和调度说明。
2. 默认工具栏只出现保存、运行和更多三个主要动作。
3. 所有低频操作可从更多菜单访问，且原有功能仍可使用。
4. 运行设置可展开并选择多个目标，运行逻辑保持不变。
5. 计划任务、运行记录、导入导出、专注编辑和 AI 能力均仍可进入。
6. 通过现有 UI 回归、构建、Rust 测试和桌面应用启动检查。
