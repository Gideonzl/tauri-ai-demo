# 本地工作流快照与数据管理设计

## 目标

为个人运维场景提供可复用的本地工作流快照，并在设置中提供简约、可理解、可彻底删除的数据管理能力。默认不上传任何业务数据，不增加常驻侧栏入口，不引入数据库浏览器或复杂仪表盘。

## 数据边界与存储位置

### 工作流快照

- 快照仅保存在当前设备的应用本地存储中，与现有命令历史、AI 对话和脚本数据保持一致。
- 一张快照包含：标题、创建时间、目标服务器引用、独立命令、命令输出、AI 结论、关联文件路径和标签。
- 快照绝不保存密码、私钥正文、API Token 或其他凭据。主机只保存名称和 ID 引用；失效引用在界面中标识为“主机已移除”。
- 首期使用浏览器 WebView 的本地存储，避免为了单机个人工具额外引入数据库与迁移成本；导出采用 JSON，便于迁移和备份。

### 凭据与偏好

- 服务器、分组和快捷命令沿用现有本地存储。
- 私钥正文与 AI Token 继续保存在应用数据目录的加密文件中，数据管理通过后端命令删除，不把凭据读回前端。
- 主题、语言、终端字体、光标和其他外观偏好被视为个人偏好，不计入“清除全部业务数据”，始终保留。

## 极简交互

### 保存快照

- 不新增常驻页面或浮动按钮。
- 在 AI 对话的相关命令/输出卡片，以及命令历史的条目菜单中提供“保存为快照”。
- 打开后仅显示一个紧凑面板：标题（可选）、标签（可选）、已包含的命令数量和保存按钮；默认标题由当前任务/第一条命令生成。
- 用户主动保存，首期不做隐式自动记录，避免积累噪声和敏感输出。

### 查看与复用

- 设置页中的“数据”区域提供一个“工作流快照”入口，打开后显示按时间倒序的简单列表。
- 列表只展示标题、服务器、时间和命令数；搜索、标签筛选及详细内容均在该页按需展开。
- 每条快照可删除、复制内容、发送给 AI 分析，或将其中某一条命令导入当前终端。执行仍遵循现有权限和目标选择逻辑。

### 数据管理

设置页的“数据”区域保持单列分类，不做图表。每项显示名称、记录数量/估算占用和一个清理按钮：

1. 工作流快照
2. AI 对话历史
3. 终端命令历史
4. 连接资料（服务器、分组、快捷命令、加密私钥）
5. 其他业务数据（脚本、计划任务、执行记录、巡检和运维报告）

- 分类清理通过二次确认执行。
- “清除全部业务数据”放在区域底部的危险操作中，明确列出将删除的五类业务数据，并要求输入 `清除` 后执行。
- 清除全部会删除加密私钥与 AI Token，但保留主题、语言、终端偏好和窗口布局等个人偏好。
- 导出/导入保留在同一数据区域；默认导出所有非敏感业务数据，不导出私钥、密码或 Token。导入前显示合并/覆盖选择，并要求确认。

## 实现边界

- 新增独立的 `workflowSnapshots` store，负责数据模型、过滤、导入导出和本地持久化；不耦合 SSH 会话、AI 通信或终端渲染代码。
- 新增后端数据维护命令，仅负责删除应用数据目录中的加密私钥和 Token；前端不接触这些明文。
- 设置页仅组合数据计数、清理操作与备份入口，不负责业务数据的具体存储实现。
- 现有 stores 增加明确的 `clear` / `export` / `import` 边界，避免通过散落的 `localStorage.removeItem` 直接删除。

## 错误处理

- 本地写入失败时保留当前编辑内容并显示简短错误提示，不生成半成品快照。
- 删除失败时显示具体类别；已成功删除的类别不会回滚。
- 导入文件格式不正确、版本不支持或包含敏感字段时，拒绝导入并解释原因。
- 删除操作不影响正在打开的 SSH 连接；连接资料被删除后，仅阻止下次重新连接。

## 验收标准

1. 用户能从一条独立命令/输出主动保存脱敏的本地工作流快照。
2. 快照可查询、查看、删除、导出，并将单条命令导入当前终端或 AI。
3. 数据管理可单独清理五类业务数据，并展示清晰的删除范围。
4. “清除全部业务数据”会删除服务器、加密私钥、AI Token、快照和其他业务数据，但保留主题、语言及终端偏好。
5. 备份文件不包含私钥、密码、Token 或其明文。
6. 通过数据模型测试、前端构建、Rust 测试和桌面启动检查。
