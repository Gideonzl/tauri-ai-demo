## 四、文件树全量加载规则

### 4.1 无过滤原则

- **隐藏文件：** 强制显示，文件名前缀`.`用淡化样式区分（`opacity: 0.6`）
- **系统文件：** 全部显示，无任何过滤
- **1panel目录：** `/opt/1panel`等全部显示
- **所有文件类型：** 无扩展名过滤，二进制/文本/配置/日志全部显示

### 4.2 文件图标映射

| 类型 | 图标 | 颜色 | 匹配规则 |
|------|------|------|---------|
| 目录 | FolderOpened | $color-warning (#d4a24e) | isDir=true |
| 隐藏目录 | FolderOpened | $color-warning (opacity:0.6) | isDir && name.startsWith('.') |
| 代码文件 | Document | $color-primary (#5b8def) | .ts/.js/.vue/.py/.rs/.go/.java |
| 配置文件 | Setting | $color-info (#7a8a9e) | .json/.yaml/.yml/.toml/.conf/.env |
| 日志文件 | Notebook | $color-text-secondary | .log |
| 压缩文件 | Files | $color-warning | .gz/.zip/.tar/.rar |
| 可执行文件 | VideoPlay | $color-success | 无扩展名+有执行权限 |
| 普通文件 | Document | $color-text-regular | 其他 |

### 4.3 排序规则

1. 目录在前，文件在后
2. 同类按名称字母排序（区分大小写）
3. 隐藏文件不单独分组，按名称排序混入

## 五、PTY终端修复规范

### 5.1 问题根因

Demo版终端使用div模拟，未接入真实PTY。cd/ls等命令在模拟模式下有硬编码响应，但无法处理任意命令。

### 5.2 修复方案

**Demo期（无真实SSH连接）：** 扩充模拟命令响应表，覆盖更多常用命令

| 命令 | 模拟输出 |
|------|---------|
| cd | 无输出（切换目录） |
| ls | 当前目录文件列表 |
| ls -la | 详细文件列表 |
| pwd | 当前路径 |
| whoami | root |
| hostname | 服务器名 |
| date | 当前时间 |
| uname -a | 系统信息 |
| cat /etc/os-release | 系统版本 |
| df -h | 磁盘使用 |
| free -h | 内存使用 |
| top | 进程列表(简化) |
| ps aux | 进程列表 |
| netstat -tlnp | 端口监听 |
| docker ps | 容器列表 |
| systemctl status | 服务状态 |
| bash | 进入子shell提示 |
| sudo | 需要密码提示 |

**真实SSH连接后：** 所有命令通过PTY直接执行，无模拟

## 六、SFTP面板在WorkspaceView中的集成

### 6.1 左侧面板动态切换

| 条件 | 左侧面板内容 |
|------|------------|
| 无SSH连接 | 服务器列表（HostList） |
| SSH已连接 | SFTP文件树（SftpTree） |
| 用户手动切换 | 可通过标签栏[Hosts]/[SFTP]切换 |

### 6.2 切换逻辑

- SSH连接成功 → 左侧自动切换为SFTP文件树
- SSH断开 → 左侧恢复为服务器列表
- 标签栏增加[Hosts]/[SFTP]切换按钮
